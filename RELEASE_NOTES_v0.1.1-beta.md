# Controle QCY H3 — 0.1.1-beta

Atualização da beta com documentação de uso e compatibilidade mais clara.

## Novidades

- O aplicativo é apresentado para **QCY H3 padrão e QCY H3S**.
- Registramos explicitamente a evidência disponível: o H3S foi testado em
  hardware; a validação do H3 padrão depende de testes em unidades de usuários.
- README refeito, três capturas de tela, FAQ, guia de compatibilidade e roteiro
  de teste.
- Endereço Bluetooth na captura de busca foi fictício/mascarado.
- Ajuste da versão exibida e do texto de compatibilidade na janela.

## Download

Baixe `Controle_QCY_H3_0.1.1-beta.exe`. É um aplicativo portátil para Windows
10/11 e não requer instalação de Python.

Esta ainda é uma versão beta. Recursos e comportamento podem variar conforme
modelo, revisão, firmware e adaptador Bluetooth. O projeto é independente e
não afiliado à QCY.
