# Identidade visual

- `qcy-h3-control.svg`: símbolo original do Controle QCY H3, desenhado em
  vetores para uso no app, documentação e lojas.
- O `.ico` Windows é renderizado a partir do mesmo SVG durante o build pelo
  script `tools/build_icon.py`, para manter as duas versões consistentes.

O projeto é uma ferramenta comunitária independente, sem afiliação oficial com
a QCY.
