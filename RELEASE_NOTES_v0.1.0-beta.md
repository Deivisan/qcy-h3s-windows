# Controle QCY H3 — 0.1.0-beta

Primeira versão beta de testes do gerenciador pessoal para Windows.

## Destaques

- Visual totalmente renovado em português, com identidade vetorial própria.
- Controles de conexão, modos de ruído, Game Mode e equalizador de 10 bandas.
- Ajuda integrada e atalhos: `Ctrl+K`, `Ctrl+G`, `Ctrl+Enter`, `Ctrl+0` e `F1`.
- H3S testado nesta máquina; H3 padrão ainda em validação.

## Instalação

Baixe `Controle_QCY_H3_0.1.0-beta.exe`, execute no Windows 10/11 e permita o
acesso ao Bluetooth. O executável é portátil; não requer Python.

## Nota beta

Esta versão é para testes. Compatibilidade pode variar conforme firmware e
adaptador Bluetooth. O projeto é independente e não afiliado à QCY.
